# 💍 Свадебное приложение-приглашение Назара и Софии
### Wedding Invitation & RSVP App (RU / HE)

Красивый, современный двуязычный свадебный сайт-приглашение с интеграцией израильского Bit, подтверждением присутствия (RSVP), мгновенными уведомлениями в Telegram и панелью владельца для жениха и невесты.

---

## 🌟 Возможности

1. **Двуязычный интерфейс (RU / עברית)**:
   - Моментальное переключение между русским и ивритом.
   - Полная поддержка RTL (чтение справа налево для иврита).
2. **Интерактивные блоки**:
   - Главный экран с таймером обратного отсчёта до дня свадьбы.
   - «Наша история» (хронология любви).
   - Фотогалерея с памятными кадрами.
   - Программа свадебного дня (сбор, хупа, банкет, танцы).
   - Локация с быстрыми кнопками навигации в **Waze** и **Google Maps**.
3. **Израильский Bit**:
   - Карточка с кнопкой моментального копирования номера телефона и прямым переходом в приложение Bit.
4. **Форма подтверждения присутствия (RSVP)**:
   - Имя и фамилия гостя.
   - Телефон (с быстрым переходом в WhatsApp).
   - Выбор: «Я приду 🎉» / «К сожалению, не смогу 💔».
   - Количество персон.
   - **Тёплые слова и мини-поздравление** молодожёнам.
   - Эффект праздничного салюта (Confetti) при отправке.
5. **Мгновенные уведомления в Telegram**:
   - Ответ гостя падает прямо на телефон жениху в личный чат Telegram через бота.
6. **Панель владельца (Admin Dashboard)** на `/admin`:
   - Защищена паролем (по умолчанию: `wedding2027admin`).
   - Статистика в реальном времени: сколько человек подтвердили, сколько отказались, сколько всего гостей придёт.
   - Таблица всех гостей, их номеров телефонов и поздравлений.
   - Выгрузка всего списка в **Excel (CSV)** одной кнопкой!

## 🚀 Как запустить локально

В терминале перейдите в папку проекта и запустите:

```bash
python3 server.py
```

После этого откройте в браузере:
* **Сайт для гостей:** [http://localhost:8080](http://localhost:8080)
* **Панель управления (для Назара и Софии):** [http://localhost:8080/admin](http://localhost:8080/admin)
  * Пароль по умолчанию: `wedding2027admin`

---

## 📱 Как настроить уведомления в Telegram за 2 минуты

1. Откройте в Telegram бот [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Введите имя для бота (например, `NazarSofiaWeddingBot`).
3. Скопируйте полученный **Token** (вида `123456789:ABCdefGhI...`).
4. Напишите боту [@userinfobot](https://t.me/userinfobot), чтобы узнать свой цифровой **Chat ID** (например, `987654321`).
5. Откройте панель управления [http://localhost:8080/admin](http://localhost:8080/admin), нажмите **«Настроить Telegram-бота»**, вставьте токен и Chat ID и нажмите **«Отправить тест»**.

Готово! Теперь каждое подтверждение гостя будет приходить вам на телефон со звуком!
